# Assets

File-file di bawah ini dipakai di preview, PDF, dan invoice yang disinkron ke Notion.

- ✅ `qr-bca.jpg` — QR code BCA CV Karya Mudra Gemilang, udah ada (di-crop dari
  file QRIS yang kamu kirim).
- ⬜ `logo-melanao.png` — logo Melanao (belum ada, masih perlu kamu isi)
- ⬜ `logo-omoji.png` — logo Omoji (belum ada, masih perlu kamu isi — file
  `IMG_2271.png` di page template Omoji di Notion)

Cara isi logo yang belum ada: buka salah satu page invoice lama di Notion →
klik kanan logonya → "Download" atau "Open original" → save, rename sesuai
nama di atas → drag ke folder `assets/` ini sebelum di-deploy.

Kalau file logo belum ada, app tetap jalan normal — cuma logo-nya kosong
(gak error).
